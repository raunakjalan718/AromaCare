Event-Driven Architecture

How It Works

Real sensor readings from the ESP32 flow through a four-stage pipeline from hardware capture to instant Web Dashboard alerts.

01

Air Sample Capture

The ESP32 reads three MQ-series gas sensors through its 12-bit ADC pins every 100 ms. Raw values (0–4095) represent ambient gas concentrations in real time.

02

Threshold Detection

Inside the ESP32 firmware, each ADC reading is compared against a threshold of 400. Readings above this limit are immediately flagged as BAD and trigger the alert pipeline.

03

WiFi HTTP API

The ESP32 hosts a lightweight HTTP server on port 80. This dashboard polls the /status endpoint every 2 seconds to retrieve JSON sensor data, statuses, and fan state.

04

Dual-Channel Alerts

Poor air quality triggers the servo-controlled fan automatically on the ESP32. Simultaneously, this dashboard fires a visual alert banner and logs the event with a full timestamp.

Key Features

A complete end-to-end platform connecting real ESP32 hardware to a premium web dashboard with persistent storage and analytics.

Live ESP32 HTTP Polling

Fetches the JSON sensor payload from the ESP32's built-in HTTP server every 2 seconds. Enter the ESP32's WiFi IP address in Settings to connect instantly.

Persistent JSON Database

Every reading is stored with a precise ISO timestamp in a LocalStorage JSON database, maintaining up to 500 historical entries that survive browser restarts.

Per-Sensor Analytics

Three dedicated Chart.js graphs — one for each MQ sensor — display raw ADC values over time with a red dashed alert threshold line and min/max/avg statistics.

Fan Status Monitoring

The dashboard mirrors the ESP32's servo fan state in real time. Alerts fire both inside the hardware (servo moves to 90°) and on-screen simultaneously.

CSV Data Export

One-click export produces a fully formatted CSV with timestamps, ADC values, GOOD/BAD statuses, and fan state for all stored records.

Secure Login Portal

Authenticated access ensures only authorised personnel can view live sensor data, configure the ESP32 connection, and manage alert thresholds.

Not configured — enter IP below
How to find your ESP32 IP
  1. Connect ESP32 to your laptop via USB cable.
  2. Open Arduino IDE → Tools → Serial Monitor.
  3. Set baud rate to 115200, press the Reset button on ESP32.
  4. Look for: IP address: 10.x.x.x
  5. Your laptop must also be on WiFi: "realme7"
If Connect fails (Vercel / CORS Error)
  1. For Vercel (HTTPS): If you are on an HTTPS site, Chrome blocks local HTTP IPs (Mixed Content). To fix: click the Lock Icon 🔒 in your browser's URL bar → Site Settings → find Insecure content and set it to Allow. Then reload the page.
  2. For CORS: Open a new Chrome tab and go to: http://10.x.x.x/status. If you see JSON, leave it open and click Connect again.
